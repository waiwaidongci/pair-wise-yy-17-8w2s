# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 调风闭环规则

- 每次巡测登记**上层（上风段）/下层（下风段）**两层温湿度，并记录层位、风向、离场时间。
- 样点档案维护**温差限值**与基准湿度；巡测保存时自动判定：
  - 两层温差（下层温度 − 上层温度）绝对值超过样点限值，或
  - 下层湿度较基准下降

  满足任一条即建立**待调风记录**；同一样点记录未结束前，后续异常只**累加次数**，不另建记录。
- 调风由巡测员登记执行人与措施，记录转为**待复测**。
- 调风满 **30 分钟**后，必须由**另一位巡测员**复测；复测读数落巡测履历，两层均恢复（温差未超限且下层湿度回到基准）才**结束**，否则继续待复测。
- 样点基准/限值或原巡测读数被修改时，未结束的记录按新值**重新判定**，判定与读数快照更新，但**旧履历全部保留**。
- 趋势看板显示每个样点的当前两层温差、下层湿度、调风状态和最近复测人。
